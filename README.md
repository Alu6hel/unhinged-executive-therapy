# Unhinged Executive Therapy 💼🤬

Laughter is the best medicine, especially when your therapist is completely out of his mind. 

This app provides comedic, stress-relieving "therapy" sessions hosted by an eccentric, highly volatile "international businessman" who operates out of a sandy trailer. Tune in for terrible life advice, aggressive motivational speeches, and pure comedic chaos.

## Features
* **Daily "Therapy" Audio:** Short, unhinged audio clips to help you laugh off daily stress.
* **Terrible Business Advice:** A daily text generator offering highly questionable corporate strategies.
* **Rage Meter:** A virtual stress toy to tap when you're frustrated, triggering comedic sound bites.

## Setup & Installation
1. Clone the repository: `git clone https://github.com/[Your-Username]/unhinged-executive-therapy.git`
2. Navigate to the directory: `cd unhinged-executive-therapy`
3. Install dependencies: `npm install` (or your chosen package manager)
4. Run the app: `npm start`
